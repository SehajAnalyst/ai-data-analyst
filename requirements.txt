# --- LLM provider SDKs --------------------------------------------------
# NOTE (production hardening pass): anthropic, openai, and
# google-generativeai are NOT currently imported anywhere in the
# codebase — only groq is actually used (see
# core/llm/llm_client_factory.py — Claude/OpenAI/Gemini raise
# ConfigurationError if requested). Deliberately kept anyway, unlike
# chromadb/sentence-transformers below: these three are modest-sized
# SDK packages (no heavy ML framework like torch), and their stub
# provider classes (core/llm/providers/claude_provider.py etc.) exist
# specifically to demonstrate the multi-provider Strategy pattern this
# architecture is built around. Removing them now would just mean
# re-adding them the moment any of those providers gets implemented,
# for negligible install-size benefit. Revisit if install size becomes
# a real constraint.
anthropic~=0.39
openai~=1.54
google-generativeai~=0.8
groq~=0.11
